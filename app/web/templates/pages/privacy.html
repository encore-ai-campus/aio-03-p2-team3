개인정보처리방침

Gmail 견적 도우미는 수업 과제용 시연 서비스입니다.

{{ banner('테스트용 Gmail 계정과 가상 메일로만 이용해 주세요. 실제 개인정보를 넣지 마세요.') }} {% call card('접근하는 Google 데이터와 이용 목적') %}
  • Google 로그인으로 이메일 주소를 확인해 사용자를 구분하고 Gmail 계정을 연결합니다.
  • gmail.readonly 권한으로 새 메일 알림을 등록하고 메일을 읽습니다.
  • gmail.send 권한으로 사용자가 승인한 답장을 발송합니다.

읽은 메일 내용과 거래 조건은 답장 후보와 견적서를 생성하는 데 사용합니다. 답장은 사용자가 내용을 확인하고 승인해야만 발송합니다.

{% endcall %} {% call card('저장 위치와 보관 기간') %}

이메일 주소, 메일 처리 데이터, 답장 후보·거래 조건 등 서비스 데이터는 배포 환경의 Render Postgres에 저장합니다. Google 접근 토큰과 갱신 토큰은 암호화해 저장합니다.

보관한 서비스 데이터와 Google 토큰은 과제 종료 뒤 삭제합니다.

{% endcall %} {% call card('AI 처리와 Google로의 전달') %}

답장 후보와 견적서 생성을 위해 메일 내용이 Google의 LLM인 Gemini 무료 등급에 전달됩니다. 무료 등급 입력은 Google 제품 개선에 쓰일 수 있습니다.

실제 개인 메일이나 실제 개인정보를 입력하지 말고, 테스트용 Gmail 계정과 가상 메일만 사용해 주세요.

{% endcall %} {% call card('연동 해제와 문의') %}

연동을 해제하려면 Google 계정 → 보안 → 타사 액세스에서 Gmail 견적 도우미의 접근 권한을 삭제해 주세요. Google 계정의 연결 관리에서 확인할 수 있습니다.

서비스와 개인정보 처리에 관한 문의는 GitHub Issue로 남겨 주세요. 공개된 공간이므로 개인정보와 메일 원문은 적지 마세요.
