개인정보처리방침

{{ app_name }} · 시행일 {{ policy_date }}

{{ app_name }}(이하 "서비스")는 수업 과제 팀 aio-03-p2-team3이 만든 시연용 웹 서비스입니다. 이 방침은 서비스가 Google 계정과 Gmail에서 어떤 정보에 접근하고, 어떻게 쓰고, 저장하고, 누구와 공유하는지 설명합니다.

{% call card('1. 접근하는 정보') %}
  • Google 계정 기본 정보(openid, 이메일 범위): 이메일 주소와 Google 계정 고유 ID. 로그인한 사용자를 구분하는 데만 씁니다.
  • Gmail 메일 읽기(gmail.readonly 범위): 새 메일 알림을 받기 위한 메일함 변경 기록, 새로 받은 메일과 같은 대화(스레드)의 보낸 사람·받는 사람·제목·본문·받은 시각.
  • Gmail 메일 보내기(gmail.send 범위): 사용자가 화면에서 직접 고르고 승인한 답장과 견적서 첨부 파일을 같은 대화로 보낼 때만 씁니다.
  • Google 로그인 토큰: 위 기능을 쓰기 위한 액세스·갱신 토큰.
  • 사용자가 입력한 정보: 설정 화면에 넣은 공급자(회사) 정보와 품목 단가표.
{% endcall %} {% call card('2. 정보를 쓰는 목적') %}
  • 받은 메일의 의도를 분석하고 답장 후보 2~3개를 만듭니다.
  • 거래 문의에서 거래처명·품목·수량·납기 같은 거래 조건을 뽑고, 빠진 항목을 확인해 다시 묻는 답장이나 견적서를 만듭니다.
  • 같은 대화의 앞선 내용과 거래 기록을 기억해 다음 답장에 반영합니다.
  • 처리 과정과 오류를 실행 기록으로 남겨 서비스를 점검합니다(기록에는 메일 본문 대신 길이만 남깁니다).

Google 사용자 데이터를 광고, 판매, 사용자 신용 평가, 위 목적과 관계없는 용도에 쓰지 않습니다. 사용자가 승인하지 않은 메일은 보내지 않습니다.

{% endcall %} {% call card('3. 다른 곳에 전달되는 정보') %}
  • OpenAI API: 메일 분석·답장 후보·거래 조건·요약·검토를 위해 메일 내용과 관련 대화·거래 기록 일부를 OpenAI API로 보냅니다. 독립 문서 작성 화면에 입력한 내용도 AI 추출을 요청하면 OpenAI API로 보냅니다. API 데이터의 보관·이용은 OpenAI의 API 데이터 안내와 서비스 계정 설정에 따릅니다. 이 서비스는 시연용이므로 실제 개인정보나 실제 업무 메일을 넣지 말고 테스트용 Gmail과 가상 메일로만 이용해 주세요.
  • Render: 서비스 서버와 데이터베이스를 운영하는 호스팅 업체입니다(싱가포르 지역).

위 경우 말고는 Google 사용자 데이터를 제3자에게 팔거나 넘기지 않습니다.

{% endcall %} {% call card('4. 저장과 보관') %}
  • 메일 정보, 답장 후보, 견적서, 설정, 실행 기록은 Render의 PostgreSQL 데이터베이스에 저장합니다. 사용자마다 본인 데이터만 볼 수 있습니다.
  • Google 토큰은 암호화해서 저장합니다.
  • 서비스는 수업 과제 기간에만 운영하며, 보관한 데이터는 과제 종료 뒤 삭제합니다. 데이터베이스는 2026년 12월에 삭제됩니다.
{% endcall %} {% call card('5. 연결 해제와 삭제 요청') %}
  • 서비스에서 로그아웃하면 새 메일 알림을 멈춥니다.
  • Google 계정 관리 → 보안 → 타사 앱 및 서비스 연결에서 이 서비스의 접근 권한을 언제든 없앨 수 있습니다. Google 계정의 연결 관리에서 확인할 수 있습니다.
  • 저장된 데이터의 삭제를 원하면 프로젝트 GitHub Issue로 요청해 주세요.
{% endcall %} {% call card('문의') %}

서비스와 개인정보 처리에 관한 문의는 GitHub Issue로 남겨 주세요. 공개된 공간이므로 개인정보와 메일 원문은 적지 마세요.
