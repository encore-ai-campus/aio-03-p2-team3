{% call card('하는 일') %}

  3. 상대방이 거래 조건(거래처명·품목·수량·납기)을 보내면 빠진 항목을 확인하고, 빠졌으면 다시 묻는 답장을, 다 있으면 견적서를 준비합니다.
  4. 사용자가 후보 하나를 직접 고르고 승인해야만 같은 메일 대화로 답장을 보냅니다. 승인 없이는 어떤 메일도 보내지 않습니다.
