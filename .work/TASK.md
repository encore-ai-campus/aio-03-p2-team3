## 이 레포의 규칙
<!-- 이 레포에만 해당하는 규칙. 고칠 때는 공통 규칙 4절을 따른다. -->
- 공통 부분: 그래프 상태 객체, 도구 스키마(입출력), 그래프 노드·엣지. 고치기 전에 관련 담당자와 조율한다. 같은 파일을 여럿이 고칠 때도 조율한다. [Request]
  - 요청자는 AI에게 맡기기 전에 조율하고, 요청에 `조율함: <담당>`을 적는다. 그 줄 없이 공통 부분을 바꿔야 하면 AI는 공통 규칙 5절 5번의 ⚠ 줄을 쓴다. [Claude proposal]
  - 공통 부분의 파일 위치는 코드 구조가 정해지면 여기에 적는다(아직 없음). [Claude proposal]
- AI에게 작업을 맡길 때 요청에 관련 상태·도구·노드, 수정 범위, 확인 조건을 적는다. [Request]
- 병합 전 절차: ① 담당자가 PR '설명' 칸에 변경 이유·입출력·상태 변화·오류 처리를 적는다(필수). ② 검토자가 정상·오류 요청의 실제 결과를 확인한다(선택, 병합 뒤 댓글도 된다). ③ 담당자가 반영한다. [Request · Claude proposal]
- 기록: 설계 결정·오류 사례·수정 이유·버전·재실행 결과를 Issue, PR('오류·재실행 기록' 칸), 팀 노션에 남긴다. [Request]
- 환경: Python 3.12, uv. 환경변수 이름은 `.env.example`에 두고, 키는 서버 환경(Render)과 Codex 환경의 비밀값에 둔다. 패키지 추가와 실행 명령은 세팅 3단계에서 README와 함께 정한다. [Request]
