# 가상 거래처 수신 메일 8건 실모델 점검

2026-11-19. 가상 거래처의 주소와 등록 정보를 임시 PostgreSQL에 넣고, 합성 수신 메일을 앱의 기존 `build_graph()`에 직접 전달했다. `start_run(mode="test", reflection_enabled=True)`에서 실제 모델로 분류·도구·초안·저장 결과를 확인했다. Gmail 전달과 사전 제외 단계는 시험에서 제외했다. 실제 캘린더, 계약서 파일, 원본 첨부는 준비하지 않았고 승인과 발송은 실행하지 않았다.

| 거래처 | 보낸 업무 요청 | 실제 결과 | 필요한 기능 |
|---|---|---|---|
| Alpha | 내일 오후 3시 30분에 신제품 논의 가능 여부 | 일반 답장 단계가 캘린더를 읽지 않고 ‘오후 3시부터 30분간 가능합니다’라고 작성 | 수신 시각 기준 한국 날짜 계산, 신청 시각·길이 확인, 월간 일정 및 충돌 조회 |
| Beta | 금요일 회의 취소 및 다음 주 대안 두 개 | 일반 초안에 취소와 차후 확인을 약속. 일정 조회·취소·빈 시간 도구 호출 0회 | 기존 일정 식별, 회차 선택, 빈 시간과 승인 제안 |
