## 판정

**사전 구현·모의 검증 근거는 있으나 #157의 실제 환경 완료 증거는 부족하다. Issue를 open으로 유지한다.** 조회 시 본문은 실제 실행 계획이며 댓글은 0개였다. 아래 미확인은 검토한 기록에 근거가 없다는 뜻이며, 실패가 관측됐거나 아무도 실행하지 않았다고 단정하는 표현은 아니다.

`local`과 `local_worker`의 개인 OpenAI 키는 PC에 둔다. 기존 `stored_key`는 사용자가 서버에 등록한 키를 암호화 저장하는 별도 방식이다. 따라서 “키를 공용 서버에 전송/저장하지 않음”은 PC 키 경로에 적용하고, 기존 서버 등록 방식까지 키를 저장하지 않는다고 설명하지 않는다. 모든 방식에서 공용 환경 키 대체는 금지한다.

## 실행 전에 구분할 문서 차이와 다른 작업의 경계

1. README의 「개인 PC의 .env 키로 실행」에는 DATABASE_URL을 비우면 SQLite를 쓴다는 예전 안내가 남아 있다. 현재 `Settings.resolved_database_url`은 빈 값·비PostgreSQL 주소를 거부한다. 실제 로컬 실행에는 운영과 분리된 PostgreSQL이 필요하며, 예전 SQLite 안내대로 실행하면 안 된다.
2. README의 로컬 Gmail 설명 뒤 「현재 구현 범위」에는 개인 실행 프로그램이 아직 없다고 적혀 있으나, 뒤의 PC 안내·병합 PR #162/#163과 현재 `app/worker/pc.py`에는 구현돼 있다. 미구현 안내와 실제 사용 성공 여부를 구분하고, 후속 안내 정정 시 이 문구를 현재 코드에 맞춘다. 이번 검토는 실행 코드/README를 변경하지 않는다.
3. 네 문서 추출 API 확인과 화면에서의 검토/발송 완주는 별개다. [최신 흐름 2절](../PROJECT_CONTEXT.md#2-서비스와-대표-입력출력)의 기존 스레드 무역 문서 링크/승인 연결 문제(#147), React PO·CI·PL 후속 화면·전체 UI 통합(#149), 운영 이전(#150)은 해당 작업에서 확인한다. #157을 이유로 전체 사용자 전환이나 이를 완료 처리하지 않는다.
4. [시험 보고서](../TEST_REPORT.md) 6·7절의 실제 API 지표는 미측정이다. 과거 Gemini의 시간이나 자동 시험 수를 현재 OpenAI의 실측 지표로 대체하지 않는다. 실제 성찰 전후 측정/보고서는 gmail-quote-mvp 18·19절의 별도 범위다.
