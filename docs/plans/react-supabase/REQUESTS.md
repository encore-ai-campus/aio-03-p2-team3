# 단계별 새 작업 요청문

각 항목을 새 Codex 작업에 하나씩 붙여넣는다. 이 폴더의 계획 PR과 PLAN의 선행 작업이 병합된 뒤 시작한다. `사람` 작업은 콘솔·운영 실행 항목이며 Codex 구현 요청 대신 해당 절의 실행 체크를 따른다. 관련 담당과 조율한 경우 요청에 실제 `조율함: ...`을 추가한다.

요청의 범위·완료 기준은 [PLAN.md](PLAN.md)의 해당 절을 원본으로 삼는다. 아래 요청문은 작업을 여는 용도이며 요구사항을 따로 복제하지 않는다.
