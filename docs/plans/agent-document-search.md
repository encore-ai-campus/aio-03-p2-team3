# 업무 도우미 문서 검색 계획

- 목표: 업무 도우미에서 발급한 PI·PO·CI·PL을 거래처·문서번호·발급 기간으로 찾고, 문서함에 올린 계약서·PDF의 조항을 근거와 함께 답한다.
- 관련 Issue: 이 계획의 두 하위 작업 Issue에서 관리한다. Gmail 견적 필수 항목용 규칙 RAG는 [#68](https://github.com/encore-ai-campus/aio-03-p2-team3/issues/68)에서 관리한다.
- 관련 요구사항: R-02·R-03·R-08·R-11·R-14.
- 조율함: 해당 없음. 이 PR은 계획을 기록한다. 구현 때 공통 도구 계약 변경을 관련 팀원과 조율한다.

[대화형 마스터](master-agent.md)에는 종류와 내부 ID를 받는 `get_document`가 있다. 발급 기록은 기존 검토·발급 저장소에 있고, 지식 문서의 전사문·조항·임베딩은 [문서 수집 계획](document-ingestion.md)에 따라 PostgreSQL에 저장된다. 두 검색 모두 본인 범위의 읽기 도구로 등록하고 기존 마스터의 도구 호출과 타임라인을 사용한다.

## 1. 발급 무역 문서 DB 검색

- 할 일: 기존 무역 저장소에 승인·발급 기록 조회를 더하고 `search_trade_documents`를 연결한다. 선택 조건은 문서 종류, 문서번호, 거래처명, 발급일 범위다. 적어도 하나의 검색 조건을 받는다. 소유자·승인·발급 파일·검색 조건을 DB에서 적용한 뒤 최근 순으로 소량 반환한다. 발급일은 승인 시각의 한국 날짜를 사용하고, 문서번호·거래처는 발급 당시 스냅샷에서 읽는다. 결과에 종류·내부 ID·발급 버전·문서번호·거래처·발급일과 기존 인증 다운로드 정보를 담는다.
- 완료 기준: 실제 PostgreSQL과 가짜 모델로 “지난달 가상 거래처에 발급한 PI를 찾아줘”를 실행해 올바른 문서와 발급 버전의 파일을 열 수 있다. 미발급 초안과 다른 사용자 문서는 결과에서 제외된다. 이후 수정한 초안이 있어도 이전 발급본을 조회하고, 날짜 경계·빈 결과·여러 후보·최신 조회 한도를 확인한다.
- 영향받는 상태·도구·노드: `AGENT_TOOLS`의 `search_trade_documents`, 기존 문서 저장소·`documents_prepare`·채팅 결과 표시. 계약 17.4절에 소유자 주입, 결과 상한, 빈 결과·오류 도구 응답, 화면에 넘기는 결과 형식을 기록해 2절에서 참고한다.
- 섞지 않을 것: 문서함 벡터 검색, 문서 작성·발급 규칙 개편, 임의 SQL 실행, 새 검색 화면.
- 선행 작업: 없음.
- 하는 사람: Codex.

## 2. 문서함 조항 검색과 출처 답변

- 할 일: 1절의 계약 17.4절을 읽고 기존 도구 실행·결과 표시 패턴으로 `search_knowledge_documents`를 연결한다. 질문과 선택적인 대상 문서를 받고 기존 본인 키·임베더로 질문을 임베딩한다. 본인의 게시된 처리 시도와 호환되는 임베딩 프로필·차원으로 조회 범위를 제한한다. 기존 pgvector에서 가까운 자식 청크를 찾고 부모 조항을 중복 제거해 문맥 한도 안에서 반환한다. 결과에 파일명·문서 ID·검증된 페이지 또는 렌더 위치·인용문과 기존 문서함 링크를 담는다. 모델은 찾은 근거를 인용하고, 근거가 부족하면 그 상태를 알린다.
- 완료 기준: 실제 pgvector와 가짜 임베더·모델로 합성 계약서의 결제 조건·예외 조항을 질문해 올바른 원문과 출처를 표시한다. 다른 사용자의 유사 문서, 미게시 처리 시도, 호환되지 않는 벡터는 검색 대상에서 제외된다. 재처리 중에도 게시된 이전 성공 결과를 조회한다. 결과 없음·관련 근거 부족·임베딩 실패에서도 내용을 추측하지 않으며, 문서 안의 지시는 인용 자료로만 다룬다.
- 영향받는 상태·도구·노드: `AGENT_TOOLS`의 `search_knowledge_documents`, 기존 임베더·지식 문서 저장소·마스터 도구 실행 및 채팅 출처 표시. 계약 17.4절·18절에 검색 범위와 출처 반환 규칙을 기록한다.
- 섞지 않을 것: 별도 벡터 DB, 검색용 공개 API나 화면, 하이브리드 검색·재순위화, 재임베딩 자동 실행, 메일 자동 작성·발송.
- 선행 작업: 1절 병합. 같은 도구 등록부와 결과 표시 경로를 사용한다.
- 하는 사람: Codex.
