# 대화형 마스터 에이전트

## 1. 업무 도구와 실행 반복 (완료)
- 할 일: 기존 StateGraph에 순차 tool calling을 연결한다. 메일 검색/조회/답장·문서 조회/작성/발급 제안·발송 제안과 추가 질문을 제공한다. 계산·소유권·승인·중복 발송 방지는 기존 서비스를 재사용한다.
- 완료 기준: 실제 도구 결과를 다음 모델 호출에 전달하고 호출 상한/실패 종료를 지킨다. 발송·발급은 사용자 승인 전 실행하지 않는다. 기존 명시적 Plan/Gmail 경로를 보존한다.
- 영향: WorkflowState, MasterNodes, 업무 어댑터와 새 도구 목록.
- 섞지 않을 것: RAG 검색, Calendar 쓰기, 별도 하위 에이전트.
- 선행 작업: 없음. 하는 사람: Codex.

## 2. PostgreSQL 저장과 인증 API (완료)
- 할 일: 공식 PostgresSaver·본인 대화 목록·실행 상태와 시작/조회/대화/질문·승인 재개를 연결한다. 키/소유자는 인증 경계에서 주입한다.
- 완료 기준: 재시작 뒤 대기 상태 복원, 본인만 조회/재개, 오래된 승인과 동시 요청 차단, 불명 발송 자동 재실행 금지.
- 영향: 기존 마스터 runtime, app.main 조립, DB 대화/체크포인트, Bearer API.
- 섞지 않을 것: 새 큐·외부 API·배포/실제 메일 발송 시험.
- 선행 작업: 1. 하는 사람: Codex.

## 3. React 대화 화면과 검증 (완료)
- 할 일: 기존 앱에 대화 목록/입력·실행 상태·질문·승인·문서/메일 결과 링크를 추가한다. 실행 중에만 조회하고 요청/타이머를 정리한다.
- 완료 기준: 실제 앱/임시 PostgreSQL/가짜 모델·Google로 대화→도구→질문/승인→실제 서비스 결과 흐름과 새로고침/소유권을 확인한다. 필요한 회귀만 검사한다.
- 영향: frontend/src/agent, 기존 라우트/탐색 메뉴.
- 섞지 않을 것: 기존 메일/문서 화면 전면 개편, SSE·WebSocket.
- 선행 작업: 2. 하는 사람: Codex.
